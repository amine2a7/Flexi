# Décisions provisoires

Le 12/10/2026, l'utilisateur a demandé d'appliquer **à titre provisoire** les recommandations du lead pour les décisions en attente, afin de construire le frontend web complet avec des données fictives. Chacune peut être changée plus tard : la colonne « Écrans concernés » indique où regarder.
Source des recommandations : avis de securite, ux, conformite, backend et design (revues dans `docs/handoff/reviews/`). Journal officiel : `docs/handoff/decisions.md` (entrée du 12/10/2026).

## Choix techniques du lead pour les données fictives (non métier)
- Comptes de test fictifs, affichés seulement en développement sur la page de connexion : `admin@flexipay.test`, `entreprise@flexipay.test`, `commercant@flexipay.test`, mot de passe `Test1234!`. Le cahier impose la MFA aux trois rôles : le code fictif `123456` vaut pour les trois comptes.
- `/` redirige selon la langue du navigateur (comportement par défaut de next-intl), puis `/fr` par défaut. À changer si le français doit être imposé.
